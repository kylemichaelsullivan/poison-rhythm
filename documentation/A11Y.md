# Accessibility — Poison Rhythm

Classroom-first a11y notes for Poison Rhythm: contrast grading, border hierarchy, keyboard/playback, and how we test.

Related: [`COLORS.md`](COLORS.md) (crayon prefs), [`TEACHERS.md`](TEACHERS.md) (classroom arcs), [`TESTING.md`](TESTING.md) (axe / Playwright).

## Contrast grades

Settings shows **US letter grades** (A / B / C / D / F). Thresholds follow WCAG 2.2 contrast ratios through C; D covers the band under the 3:1 UI floor. The meter lists the ratios instead of a slogan.

| Grade | Ratio | Meaning |
|-------|-------|---------|
| **A** | ≥ 7:1 | Strongest contrast |
| **B** | ≥ 4.5:1 | Clear text contrast |
| **C** | ≥ 3:1 | UI / large-text floor |
| **D** | ≥ 2:1 | Weak but not collapsed |
| **F** | &lt; 2:1 | Too weak |

**Dominant** limiting ratio is the worst of text-on-fill, accent vs light surface, and brightened accent vs dark surface. **Secondary** uses UI vs light/dark only. Both roles use the same letter scale.

The **pair meter** is one number: contrast between Dominant and Secondary. Grade **A** is 7:1 or better. Same crayon twice is 1:1, grade **F**.

**Brand default** (purple-deep `#783b82` + deep mint `#246028`) is the product pair; those two hues sit near the same luminance, so their mutual ratio is about 1:1. Suggested Pairings are separate: each is grade **A** (7:1 or better) and uses a different hue against Black, the only crayon that clears that bar with the rest of the tray.

Implementation: `gradeFromRatio`, `rateCrayonContrast`, `ratePairSeparation`, `rateColorPairContrast`, `ratePairIfRolePicked` in [`src/lib/colors/contrast.ts`](../src/lib/colors/contrast.ts).

**Settings → Colors**

- Pair meter shows a large letter and one large ratio: Dominant against Secondary.
- Each crayon swatch’s badge shows what the **pair meter would become** if that crayon were picked for the active role (`ratePairIfRolePicked`), holding the other role fixed.
- Tray selection chrome: the active role’s crayon uses **active** border + raised shadow; the other role’s crayon uses **emphasis** border + softer shadow (`data-swatch-emphasis`). Switching Dominant ↔ Secondary swaps which pick is stronger.
- Picks are **never blocked**. **A/B** use solid hierarchy borders; **F** uses dashed + dimmed chrome so clearer crayons feel better to choose.
- Suggested Pairings (Brand first) remain the fast recovery path.

Theme and display stay under **Settings → Look**.

Do not rely on accent color alone for poison identity or playback state — labels, layout, and motion also carry meaning.

## Border hierarchy

Shared convention in [`src/lib/hierarchy-border.ts`](../src/lib/hierarchy-border.ts). **Weight + style** imply order; color tone is secondary.

| Rank | Style | Use today |
|------|-------|-----------|
| **active** | `border-2` solid | Selected high-grade swatch; **Playing** measure shell |
| **emphasis** | `border-2` solid (softer tone) | Strong unselected A/B swatches; idle measure shell; selected C |
| **structure** | `border` solid | Beat groups inside a measure; quiet C swatches |
| **provisional** | `border-2` dashed | F swatches; **count-in** / **Listening** measure shells |

Live measures consume this via [`measure-phase-chrome.ts`](../src/components/measures/measure-phase-chrome.ts). **Jazz Mode** (and any future note chrome) should import `hierarchyBorderClass` / `hierarchyRankForContrastGrade` instead of inventing a parallel dashed/solid language. Keep border width constant across playback phases so the carousel does not jump.

## Keyboard, focus, and playback

- Focus rings use shared `focusVisibleRingClassName` (`ring-2 ring-primary`).
- **Escape** stops measure/metronome playback (`MetronomeProvider`); ignored in text inputs and dialogs.
- Modals trap focus via `useModalFocusTrap`; scrim / X / Escape dismiss (`ModalScrim`, `ModalCloseButton`). The difficulty regen acknowledgement (`DifficultyRegenAckHost`) has no OK button: it closes on its own after `TIMED_NOTICE_DURATION_MS` (2.5 seconds). Hovering the dialog pauses that timer and the progress bar; leaving resumes them. X, scrim, or Escape still dismiss it sooner. `prefers-reduced-motion` shows the full progress gradient immediately; the timer still runs.
- Skip link targets the beat selector inside the metronome panel.

## Projection tip

Very bright yellows/whites wash out on classroom projectors. Prefer grade **A/B** crayons or the Brand pairing for shared screens.
